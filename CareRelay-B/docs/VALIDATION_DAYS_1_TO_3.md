## Automated result

59 tests passed through scripts/start.ps1 -Mode test using the project's installed, pinned dependencies.
The original suite had 33 tests. The refreshed suite includes additional provider-envelope cases and 24 date/provenance/validation scenarios.
The existing Starlette httpx TestClient deprecation warning remains non-fatal.

Verified behavior:
- The three original records still produce six accepted, chronologically ordered events.
- Every accepted fact has an exact original-source quote and correct Unicode offsets.
- Date headers and unambiguous metadata normalize to ISO dates; each event exposes derived date provenance.
- Missing, invalid, ambiguous or conflicting dates fail with 422 and preserve the prior analysis.
- Source-header masking never fabricates a quote or changes original offsets.
- Standalone candidate validation returns accepted/rejected events without saving them or creating an analysis.
- Candidate validation uses the current originals, not stale demo records.
- Derived provenance cannot be injected through the input schema.
- Provenance and rejected-candidate data survive reloads; provenance survives an application restart.
- Unsupported quotes, sources, dates, concepts, subject changes and negation removal are rejected.
- Mocked live-provider success is validated before persistence; refusal, network failure, malformed JSON and malformed envelopes fail safely.
- Signal, navigation and action endpoints remain outside this release.
